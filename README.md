# Pursuing Coding

一个纯静态的编程语言学习入口页，作为 `Pursuing Coding` 组织首页发布到 GitHub Pages。

## 线上地址

- 组织首页：<https://pursuing-coding.github.io/>

## 当前入口

- C++ 在线实验室：<https://pursuing-coding.github.io/cpp-learn/>
- Java 学习路径：<https://pursuing-coding.github.io/java-path/>

页面只负责跳转到已有学习工具，不嵌入课程、不代理内容、不包含私人礼物项目。

## 发布配置

- 仓库：`pursuing-coding/pursuing-coding.github.io`
- Pages：`main /`
- 入口文件：

```text
index.html
```

如后续两个学习工具的网页地址发生变化，只需要改 `index.html` 中两个课程卡片的 `href`。
